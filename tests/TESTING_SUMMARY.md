# Test Suite Summary

## Overview

The `topochange` test suite validates the full package: raster and point cloud I/O, CRS and datum management, point cloud alignment, variogram analysis and model fitting, uncertainty propagation, data access pipelines, and end-to-end integration workflows. Most tests use synthetic data generated by session-scoped fixtures so they run without external files.

## Summary Statistics

- **Test files:** 18 (16 collected by pytest + 2 standalone diagnostic scripts)
- **Test functions:** ~760
- **Test classes:** ~160
- **Lines of test code:** ~10,000

## Running the Tests

```bash
# Minimal (runs ~600+ tests without optional deps)
pip install -e ".[dev]"
pytest

# Full suite (runs all ~760 tests)
pip install -e ".[dev,pointcloud,alignment]"
conda install -c conda-forge pdal python-pdal gdal
pytest

# With coverage
pytest --cov=topochange --cov-report=html

# Skip slow tests
pytest -m "not slow"

# By marker
pytest -m alignment
pytest -m metadata
pytest -m transformation
pytest -m dem
pytest -m integration
```
